# 📚 数据格式详解

`novel_to_drama` 支持灵活的数据格式，推荐使用 **TXT 格式**（更易编写和维护）。

---

## 1. 角色设定文件

### 支持的文件名

优先级从高到低：
1. `characters.json` - JSON 格式
2. `characters.txt` - TXT 格式（推荐）
3. `角色设定.txt` - TXT 格式
4. `人设.txt` - TXT 格式
5. `人物设定.txt` - TXT 格式

### TXT 格式（推荐）

**格式一：分段式（推荐）**

```
【林枫】
姓名：林枫
年龄：25
身份：商业天才、家族继承人
性格：冷静、果断、外表玩世不恭但内心有底线
外貌：身材高大，眼神锐利，常穿黑色西装
说话风格：简短有力，喜欢用反问句，不废话
口头禅：有意思、你确定？

【苏晴】
姓名：苏晴
年龄：23
身份：公司职员，隐藏身份是千金小姐
性格：温柔但坚韧，不善言辞但内心强大
外貌：清秀端庄，眼神清澈，常穿职业装
说话风格：语气温和，但有原则，关键时刻很坚定
口头禅：我知道了、我会努力的
```

**格式二：键值式**

```
林枫：
  姓名：林枫
  年龄：25
  身份：商业天才
  
苏晴：
  姓名：苏晴
  年龄：23
  身份：公司职员
```

### JSON 格式（兼容）

```json
{
  "林枫": {
    "姓名": "林枫",
    "年龄": 25,
    "身份": "商业天才、家族继承人",
    "性格": "冷静、果断",
    "外貌": "身材高大，眼神锐利",
    "说话风格": "简短有力",
    "口头禅": "有意思"
  }
}
```

## 2. 目录文件

### 支持的文件名

优先级从高到低：
1. `toc.json` - JSON 格式
2. `toc.txt` - TXT 格式（推荐）
3. `目录.txt` - TXT 格式
4. `章节目录.txt` - TXT 格式

### TXT 格式（推荐）

**格式一：第N章 标题（推荐）**

```
第1章 危机降临
第2章 暗流涌动
第3章 正面交锋
第4章 峰回路转
第5章 身份曝光
第6章 最终对决
```

**格式二：中文数字**

```
第一章 危机降临
第二章 暗流涌动
第三章 正面交锋
```

**格式三：数字. 标题**

```
1. 危机降临
2. 暗流涌动
3. 正面交锋
```

**格式四：纯标题（自动编号）**

```
危机降临
暗流涌动
正面交锋
```

### JSON 格式（兼容）

```json
[
  {"chapter": 1, "title": "危机降临"},
  {"chapter": 2, "title": "暗流涌动"},
  {"chapter": 3, "title": "正面交锋"}
]
```

### 自动生成

如果没有任何目录文件，系统会：
1. 扫描 `chapters/` 目录
2. 读取每个章节文件的第一行作为标题
3. 自动生成目录

---

## 3. 章节文件

### 文件命名

必须遵循以下格式：
- `chapter_1.txt` - 第1章
- `chapter_2.txt` - 第2章
- `chapter_3.txt` - 第3章
- ...

### 文件内容

```
第一章标题（可选）

正文内容...
```

第一行如果是标题（少于50字），会被提取为章节标题。

## 5. 数据加载优先级

系统会按以下优先级加载数据：

### 角色设定

1. `characters.json`
2. `characters.txt`
3. `角色设定.txt`
4. `人设.txt`
5. `人物设定.txt`

### 目录

1. `toc.json`
2. `toc.txt`
3. `目录.txt`
4. `章节目录.txt`
5. 自动生成（扫描 chapters 目录）

## 6. 常见问题

### Q1: TXT 文件编码问题？

确保文件使用 **UTF-8 编码**保存。

### Q2: 角色设定解析失败？

检查：
- 是否使用了 `【角色名】` 格式
- 键值对是否使用 `：`（中文冒号）或 `:`（英文冒号）
- 每个角色之间是否有空行分隔

### Q3: 目录解析失败？

检查：
- 是否使用了支持的格式
- 章节编号是否连续
- 标题是否在同一行
